# Kwok Wah Tyre Management App

A full-stack business management app for tyre-shop inventory, orders, invoices, and reporting.

## Stack

- React, TypeScript, Vite, Tailwind CSS
- Express and Drizzle ORM
- PostgreSQL

## Run locally

1. Install Node.js 20 and PostgreSQL.
2. Install dependencies with npm install.
3. Configure DATABASE_URL and SESSION_SECRET in your local environment. Configure AI_INTEGRATIONS_OPENAI_API_KEY and AI_INTEGRATIONS_OPENAI_BASE_URL if using AI invoice scanning. Do not commit secret values.
4. Start the development server with npm run dev.
5. Create or initialize the database schema using the project's existing Drizzle setup.

Use npm run build to build the app.

## Data and credentials

This repository contains application source only. It does not contain customer, invoice, or inventory exports, local screenshots, private photo uploads, internal Replit notes, or login credentials. Create or configure an administrator account securely for your deployment.
